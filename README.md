# Clone App Template — শুধু কপি-পেস্ট করে APK বানান

কোনো কোডিং জানা লাগবে না। শুধু ৩টা ফাইল এডিট করবেন, বাকিটা GitHub নিজেই বানাবে।

## ধাপ ১ — GitHub এ আপলোড
1. GitHub এ একটা নতুন **Repository** বানান (Public)
2. এই zip টা এক্সট্র্যাক্ট করে সব ফাইল ঐ repo তে আপলোড করুন
   (GitHub website থেকে "Add file" → "Upload files" দিয়ে ড্র্যাগ-ড্রপ করলেই হবে)

⚠️ **খুব জরুরি:** `gradlew`, `gradlew.bat` আর `gradle/` ফোল্ডারটা অবশ্যই আপলোড করতে হবে।
এগুলোই Gradle wrapper — এগুলো ছাড়া build চালু হওয়ার আগেই fail করবে
("Grant execute permission for gradlew" স্টেপে লাল ❌ দেখাবে)।

## ধাপ ২ — App এর নাম বদলান
ফাইল: `app/src/main/res/values/strings.xml`
এখানে `My Clone App` এর জায়গায় আপনার অ্যাপের নাম লিখুন।

## ধাপ ৩ — Color বদলান
ফাইল: `app/src/main/res/values/colors.xml`
`#FF5722` এর জায়গায় আপনার পছন্দের hex color code বসান
(গুগলে সার্চ করুন "color picker hex code" — যেকোনো কালার বাছাই করে কোডটা কপি করুন)

## ধাপ ৪ — Icon বদলান (ঐচ্ছিক)
`app/src/main/res/mipmap-xxxhdpi/ic_launcher.png` ফাইলটা রিপ্লেস করুন আপনার নিজের
আইকন ছবি দিয়ে (512x512 বা 192x192 সাইজের PNG)। বাকি mipmap ফোল্ডারেও একই কাজ করলে
সব ডিভাইসে ভালো দেখাবে, না করলেও চলবে।

## ধাপ ৫ — ওয়েবসাইট/লিংক বদলান (যদি WebView অ্যাপ বানাতে চান)
ফাইল: `app/src/main/java/com/clone/app/MainActivity.java`
`https://example.com` এর জায়গায় আপনার ওয়েবসাইটের লিংক বসান।

## ধাপ ৬ — Build চালু করুন
1. GitHub repo তে যান → উপরে **Actions** ট্যাব এ ক্লিক করুন
2. বাম পাশে **Build Clone APK** ক্লিক করুন
3. ডান পাশে **Run workflow** বাটনে ক্লিক করুন
4. ১-২ মিনিট পর রিফ্রেশ দিন, রান শেষ হলে ক্লিক করে ভেতরে ঢুকুন
5. নিচে **Artifacts** সেকশনে `clone-app-apk` নামে একটা zip পাবেন — ডাউনলোড করুন
6. ঐ zip এর ভেতরে আপনার আসল `.apk` ফাইল, ফোনে ইনস্টল করে ফেলুন

## একাধিক অ্যাপ বানাতে চাইলে
প্রতিটা আলাদা অ্যাপের জন্য এই একই টেমপ্লেট আলাদা GitHub repo তে আপলোড করে
২,৩,৪,৫ ধাপ আলাদাভাবে করুন — প্রতিটা repo থেকে আলাদা branded APK বের হবে।

## গুরুত্বপূর্ণ কথা
- এইটা একটা ফাঁকা টেমপ্লেট (আপনার নিজের অ্যাপ/ওয়েবসাইটের জন্য)।
- অন্য কারো তৈরি করা (Facebook, PUBG, ইত্যাদির মতো) অ্যাপ হুবহু কপি করে
  নিজের নামে Play Store এ ছাড়া কপিরাইট আইনে সমস্যা — নিজের কনটেন্ট/ওয়েবসাইটের
  জন্য ব্যবহার করাই নিরাপদ।
